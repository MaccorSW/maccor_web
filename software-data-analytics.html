OVERVIEW

Software Designed for Battery Scientists, Not IT Departments

Battery test hardware is only as useful as the software controlling it. Maccor's software suite is built around the actual workflows of battery engineers — not generic automation frameworks retrofitted for lab use. Every feature, from drag-and-drop test step creation to multi-channel real-time plotting, is designed to minimize friction between an idea and a result.

MacTest32 provides unified control and monitoring for all Maccor hardware platforms. Build Test enables test protocol creation without coding. Advanced plotting and analytics tools turn raw cycle data into actionable insights — and our open API means you can connect Maccor data to any LIMS, cloud platform, or custom analysis environment.

SOFTWARE MODULES

The Complete Maccor Software Suite

🖥️

MacTest32

The core control and monitoring application for all Maccor hardware platforms. Manage multi-channel tests, view real-time data, respond to alarms, and access the complete test history from a single interface.

  • Real-time multi-channel monitoring
  • Hardware control and configuration
  • Alarm management & safety limits
  • Complete test history & audit trail
🏗️

Build Test

Drag-and-drop test protocol creation — no programming required. Build complex charge/discharge sequences, conditional branches, and safety triggers visually, then deploy across any channel in seconds.

  • Visual drag-and-drop editor
  • Library of standard test steps
  • Conditional logic & loops
  • Protocol sharing across teams
📈

Data Analytics & Plotting

Advanced multi-channel data visualization with overlay, differential, and derived channel analysis. Export publication-quality plots or raw data for post-processing in external tools.

  • Multi-run overlay and comparison
  • Derived parameter calculation
  • dQ/dV, dV/dQ differential plots
  • Export to Python, MATLAB, Excel
🔌

API & Custom Integration

Open API for programmatic access to Maccor hardware and data. Connect to your LIMS, trigger tests from external systems, push data to cloud analytics pipelines, or build custom GUIs.

  • REST API for hardware control
  • Streaming data output
  • LIMS / cloud platform connectors
  • Custom feature development available
