Series 1100 — Auxiliary Input Expander

✓ Field Installable

Running out of auxiliary input slots in your battery test system? The Series 1100 is a dedicated auxiliary input expansion unit that holds up to six auxiliary input panels per enclosure. Install the Series 1100 physically close to your test subjects to minimise cable runs and eliminate clutter — a single cable connects it back to your Maccor battery test system.

The Series 1100 is compatible with all auxiliary voltage, temperature, pressure, and digital I/O option boards, making it the most flexible way to scale auxiliary sensing capacity without modifying the host cycler.

Up to 6 panels Single cable connection Locate near DUT Reduces cable clutter

#AuxV

Auxiliary Voltage Inputs

✓ Field Installable

Add fully-isolated, high-impedance, software-assignable voltage inputs in blocks of sixteen. Assign any combination of voltage inputs to any test channel — measured values are seamlessly integrated into the channel's data record in real time.

Auxiliary voltage inputs are ideal for logging reference electrode voltage, monitoring individual cell voltages within a pack, or capturing any external voltage signal you need to correlate with the cycling data. Measured values can drive test-flow branching decisions — step to any other step in the procedure based on an auxiliary voltage reading.

Blocks of 16 Fully isolated High impedance Software assignable Real-time display Test-flow control

#AuxT

Temperature Inputs

✓ Field Installable

Integrate software-assignable temperature inputs in blocks of sixteen. Assign inputs to any channel to build a complete historical temperature record alongside your cycling data — no post-processing or synchronization required.

Temperature functions allow you to control test flow using absolute temperature, ∆T/δt (rate of change), ∆T (differential), and additional parameters. Branch to any test step based on a temperature condition — essential for thermal characterization, abuse testing, and safety protocols.

Thermocouple K, T, J Thermistors RTDs Absolute temp control ∆T / ∆T per time Blocks of 16

#pressure

Pressure Inputs

✓ Field Installable

Assign pressure inputs via software to any test channel, conveniently grouped in blocks of sixteen. Capture and analyse historical pressure data alongside your electrochemical measurements — particularly valuable for solid-state cell research and pouch cell swelling characterisation.

Pressure readings can actively control test flow using absolute pressure, ∆P/δt, ∆P, and additional parameters — enabling pressure-triggered safety cutoffs, conditional charge/discharge sequences, and full pressure-correlated cycle-life datasets.

#smb_

SMBus (I²C) Interface

✓ Field Installable

The SMBus interface reads data directly from battery packs fitted with SMB electronics — the BMS data stream becomes a permanent part of the channel's data file record alongside all other cycling measurements.

This enables direct comparison between Maccor's independently measured values and the data reported by the pack's own battery management system — invaluable for BMS validation, state-of-charge accuracy testing, and pack qualification. No separate data capture or post-processing merge is required.

I²C protocol BMS data capture Permanent data record BMS vs measured comparison

#canIt

CAN Bus Interface

✓ Field Installable

The CAN interface enables Maccor test systems to send and receive CAN communications from battery modules, packs, and BMS units throughout the test procedure. All CAN frame data is stored directly in the data file — no external logging hardware required.

CAN message specifications are configured by mutual agreement with Maccor engineering, supporting custom DBC definitions and flexible frame mapping. Combine with MacTest32's conditional step logic to branch test flow based on CAN-sourced values — for example, BMS-reported state-of-health, temperature limits, or fault flags.

Send & receive frames DBC configuration Stored in data file CAN-triggered step logic Custom frame mapping

EIS Electrochemical Interface — AC Impedance Multiplexer

✓ Field Installable

Connect Maccor test channels directly to a supported impedance analyser. When a test procedure reaches the designated EIS step, the channel automatically switches in the impedance analyser hardware — no manual intervention, no test interruption, no separate data session to merge.

This integrated approach dramatically increases EIS throughput: multiple channels share a single analyser through the multiplexer, and impedance spectra are collected at precisely the right state-of-charge or cycle count as defined in the MacTest32 procedure. Results are correlated directly with the concurrent cycling data.

#DigIn

Digital Inputs & Outputs

✓ Field Installable

Each Digital I/O board provides 16 opto-isolated bipolar inputs with a factory-settable voltage threshold and 16 normally-open dry-contact outputs rated at 2A. Use the digital inputs to receive signals from external safety systems, thermal chambers, or custom test fixtures and branch the test procedure accordingly. Use the digital outputs to activate relays, contactors, or external devices at any step.

With Digital I/O added to your system, you can branch to any test step based on an external signal or close a relay to activate an external device — enabling tight integration with lab automation, environmental chambers, and safety interlock systems.

16 opto-isolated inputs 16 N.O. relay outputs 2A output rating Step-flow branching External device activation Safety interlock ready

#ecc_elc

External Charge & Load Controllers (ECC / ELC)

✓ Field Installable

External Charge Controllers (ECC) can be added to any or all test channels. When a test step calls for it, the channel connects to an external charger — while retaining all of its own data-gathering capabilities, voltage and current monitoring, and all step end conditions. The ECC is ideal for verifying the performance of a third-party charger while Maccor records the full current/voltage/time dataset as if it were an internal step.

External Load Controllers (ELC) work on the same principle for discharge. Switch in your own external load during a designated step while the Maccor channel continues logging all parameters and enforcing all end conditions. This is particularly useful for validating custom discharge electronics or testing cells under application-specific load profiles that fall outside the cycler's native current range.

Add to any channel Full data logging retained All end conditions active 3rd-party charger validation Custom load integration Per-step switching
