Compact Temperature Chamber
Built to Integrate with Maccor

A compact heat/cool chamber with roughly 1 ft³ of workable area that plugs straight into your Maccor test system. Set chamber temperature as a step in your test procedure, run up to 32 addressable chambers from one PC, and stack up to four in a standard 19″ rack.

SEAMLESS INTEGRATION

Controlled Directly from Your Maccor Test Procedure.

There is no separate chamber software to learn or sync. Automatic Temperature Control lets you set the chamber temperature directly from Maccor's test system software as a step in the test procedure — so thermal set points live right alongside your charge, discharge, and rest steps.

Addressable chamber controllers let a single Maccor test system integrate up to 32 chambers, making it simple to scale temperature testing across a large channel count without adding controllers or PCs.

Why It Integrates So Easily

  • Temperature as a test step — set points programmed inside the Maccor procedure, no external controller software
  • Addressable controllers — up to 32 chambers on one Maccor test system
  • Optional Maccor interface inside — a standard Maccor interface can be added within the chamber for clean cell connections at temperature
  • Compact 7U design — only 12.25″ tall, ready for benchtop or rack
  • Heat/cool configuration — 250 W (850 BTU/hour) across +10°C to +100°C
CONFIGURATIONS

DESIGNED FOR THE LAB

Compact, Scalable Temperature Testing.

With roughly a cubic foot of workable space and a heat/cool configuration spanning +10°C to +100°C, the chamber handles everyday temperature-dependent testing while staying small enough for a benchtop. Tight ±0.5°C uniformity and accuracy keep conditions consistent across the work area.

When you need more capacity, the low 7U profile lets you rack up to four chambers together — all still driven from the same Maccor test system your team already knows.
