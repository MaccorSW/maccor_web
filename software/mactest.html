OVERVIEW

What MacTest Does

MacTest32 is the primary operator interface for every Maccor test system. It runs on the host PC and maintains continuous communication with the test hardware, translating procedure files into real-time hardware commands while streaming live electrical data back to the display. Every channel on every connected tester is visible from a single Schedule view — voltage, current, capacity, energy, step, mode, cycle count, and elapsed time — updated continuously throughout the test.

FIVE SCREEN TYPES

Monitor Views

  • Schedule screen: All channels in one table — the primary overview for multi-channel labs
  • Channel screen: Full detail for a single channel including end condition thresholds and loop counters
  • Chart screen: Live strip chart of voltage, current, and auxiliary inputs for one active channel
  • Aux screen: Real-time display of all 48 auxiliary inputs assigned to a channel
  • SMBus screen: Live register values from smart battery packs communicating via SMBus
KEY FEATURES

Capabilities

  • Assign and launch procedures on individual channels or groups
  • Advanced Start — resume a test from a specific step, preserving all accumulated data
  • Barcode integration for per-cell traceability in formation and production programs
  • Fault handling with configurable responses — stop, continue, or branch to a safe step
  • Digital I/O monitoring showing the real-time state of all 16 I/O lines
  • CAN Bus live data display when a CAN module is connected
  • Procedure synchronisation — push procedure updates from server to all client PCs
FAQ

Frequently Asked Questions

Can MacTest resume a test after a power interruption?

Yes. The Advanced Start feature allows a test to restart from any step in the procedure. The tester firmware continues running the procedure locally if the host PC loses connection — MacTest reconnects and resumes monitoring without data loss.

How many channels can MacTest monitor simultaneously?

MacTest can monitor all channels across all connected Maccor testers from a single instance. Typical lab configurations range from 8 to 256+ channels depending on system configuration.
