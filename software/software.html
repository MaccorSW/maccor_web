Software Modules

Every Tool in the Suite

Eight purpose-built applications covering the full test lifecycle. All modules ship with every Maccor system at no additional cost.

Test Execution

MacTest

Real-time channel monitor, procedure launcher, and hardware communication bridge. The central command interface for all active test positions.

Explore MacTest →
Procedure Design

Build Test

Grid-based procedure editor with syntax checking, CC-CV single-step support, conditional branching, and up to 127 steps plus subroutines.

Explore Build Test →
Data Analysis

MIMS Client

Advanced charting and statistical analysis — capacity fade, dQ/dV, efficiency trends, multi-file overlays, and one-click report templates.

Explore MIMS Client →
Data Management

MIMS Server

Centralised data collection from all connected testers. Automatic binary backups, optional ASCII generation, and procedure synchronisation across the lab.

Explore MIMS Server →
Data Export

Data Export

Convert binary test files to ASCII, Excel, or CSV. Select fields, configure delimiters, split large files, and generate per-cycle summary exports.
